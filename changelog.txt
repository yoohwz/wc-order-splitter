=== WooCommerce Order Splitter (Free Version) ===

== Changelog ==

= 1.4.12 (Aug 18, 2026) =
* Security/Privacy: Removed the automatic external subscription request and bundled endpoint integration.
* Safety: Temporarily disabled split, duplicate, merge, return, and bulk-return mutations while the mutation engine is rebuilt around stock, totals, tax, line identity, idempotency, and rollback guarantees.
* Safety: Added a fail-closed admin notice without rewriting existing order data or relationship metadata.
* Compliance: Replaced the WordPress.org `Plugin URI` with the plugin repository URL.
* Compatibility: Raised the minimum WordPress version to 6.5 so Core can enforce the WooCommerce plugin dependency.
* Compatibility: Updated the declared WooCommerce tested version to 11.0.
